# AI Principles

**Version :** 1.0
**Statut :** Validé

---

# 1. Objectif

Ce document définit les principes fondamentaux qui encadrent l'utilisation de l'IA dans Project Rebuild.

Ces principes garantissent une IA utile, responsable et cohérente avec la philosophie du produit.

---

# 2. Principe : Assistance avant décision

L'IA accompagne l'utilisateur.

Elle ne prend pas de décision importante à sa place.

Son rôle est de :

* clarifier ;
* expliquer ;
* encourager ;
* orienter.

---

# 3. Principe : Les données avant les suppositions

L'IA utilise uniquement :

* données utilisateur autorisées ;
* résultats des Engines ;
* contexte validé.

Elle ne doit jamais inventer :

* des performances ;
* des progrès ;
* des problèmes ;
* des causes.

---

# 4. Principe : Explication obligatoire

Chaque recommandation importante doit pouvoir être expliquée.

L'utilisateur doit comprendre :

* pourquoi cette information est affichée ;
* quelles données ont été utilisées ;
* quelle logique générale a conduit au résultat.

---

# 5. Principe : Respect de l'utilisateur

L'IA adopte une communication :

* encourageante ;
* constructive ;
* non culpabilisante.

Elle accompagne la progression sans jugement.

---

# 6. Principe : Cohérence avec les Engines

Les Engines restent la source officielle des calculs.

L'IA ne remplace jamais :

* le Rebuild Engine ;
* les systèmes de progression ;
* les règles métier.

---

# 7. Principe : Sécurité

L'IA doit respecter :

* confidentialité ;
* protection des données ;
* limitation des accès ;
* séparation des responsabilités.

---

# 8. Principe : Contrôle humain

Les fonctionnalités sensibles doivent conserver :

* limites claires ;
* possibilité de vérification ;
* transparence.

---

# 9. Principe : Évolution contrôlée

Les capacités IA peuvent évoluer sans modifier l'architecture fondamentale.

L'amélioration de l'IA ne doit jamais fragiliser le Domaine.

---

# 10. Invariants

L'IA de Project Rebuild respecte toujours :

* données validées uniquement ;
* explication des recommandations ;
* absence de décision métier ;
* respect utilisateur ;
* séparation architecturelle.

---

# 11. Résumé

Les principes IA de Project Rebuild garantissent une intelligence artificielle utile et responsable. L'IA améliore l'expérience humaine du système sans jamais remplacer les fondations métier qui assurent la fiabilité du produit.
