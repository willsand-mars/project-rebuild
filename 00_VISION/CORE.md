# CORE RULES

Ce document définit les règles fondamentales.

Elles ne doivent jamais être contournées.

---

RULE 001

Chaque utilisateur possède au minimum un Profil.

---

RULE 002

Toutes les données appartiennent à un Profil.

Jamais directement à l'utilisateur.

---

RULE 003

Un Profil possède plusieurs Objectifs.

---

RULE 004

Un Objectif génère plusieurs Missions.

---

RULE 005

Une Mission possède toujours :

- une difficulté
- une récompense
- une durée
- un état

---

RULE 006

Toute Mission terminée produit de l'XP.

---

RULE 007

L'XP fait progresser le Niveau.

---

RULE 008

Les Badges ne sont jamais attribués manuellement.

Ils sont uniquement débloqués par des Achievements.

---

RULE 009

Le Coach IA ne crée jamais de données.

Il interprète les données existantes.

---

RULE 010

Toutes les recommandations doivent pouvoir être justifiées.

Aucune décision n'est aléatoire.

---

RULE 011

Toutes les recommandations doivent être explicables.

---

RULE 012

Toutes les données utilisateur sont historisées.

Aucune information importante n'est écrasée.

---

RULE 013

Les calculs sont réalisés par les Engines.

Jamais par l'interface graphique.

---

RULE 014

L'interface n'est qu'une représentation.

La logique métier appartient exclusivement au domaine.

---

RULE 015

Chaque nouvelle fonctionnalité doit respecter ces règles.
