# Design System

**Version :** 1.0
**Statut :** Validé

---

# 1. Objectif

Ce document définit le Design System de Project Rebuild.

Le Design System constitue la base visuelle commune utilisée par toutes les interfaces du produit.

Son objectif est de garantir :

* cohérence graphique ;
* expérience utilisateur homogène ;
* rapidité de développement ;
* évolutivité du produit.

---

# 2. Philosophie visuelle

Project Rebuild possède une identité originale inspirée du rétro-futurisme des années 80.

L'utilisateur ne consulte pas un tableau de bord classique.

Il entre dans un univers de progression personnelle.

L'interface doit transmettre :

* énergie ;
* évolution ;
* accomplissement ;
* transformation.

---

# 3. Direction artistique

Les principes visuels principaux sont :

* néons ;
* atmosphère coucher de soleil ;
* esthétique Miami futuriste ;
* contrastes lumineux ;
* surfaces vitrées ;
* profondeur ;
* animations élégantes.

L'objectif est une identité premium et immersive.

---

# 4. Palette

La palette principale utilise :

## Couleurs principales

* violet profond ;
* rose néon ;
* cyan lumineux.

---

## Couleurs secondaires

* noir spatial ;
* bleu nuit ;
* tons sombres de contraste.

---

## Couleurs fonctionnelles

Les couleurs fonctionnelles indiquent uniquement un état :

* succès ;
* attention ;
* erreur ;
* information.

Elles ne remplacent jamais une explication utilisateur.

---

# 5. Typographie

La typographie doit respecter :

* lisibilité ;
* modernité ;
* personnalité.

Elle doit fonctionner aussi bien pour :

* les grands titres ;
* les statistiques ;
* les textes narratifs ;
* les notifications.

---

# 6. Composants visuels fondamentaux

Le Design System définit notamment :

* boutons ;
* cartes ;
* panneaux ;
* badges ;
* indicateurs de progression ;
* barres XP ;
* notifications ;
* fenêtres modales.

Chaque composant possède :

* états ;
* variantes ;
* règles d'utilisation.

---

# 7. Glassmorphism

Le glassmorphism est un élément central de l'identité.

Il utilise :

* transparence ;
* flou ;
* profondeur ;
* reflets subtils.

Il doit améliorer la hiérarchie visuelle sans réduire la lisibilité.

---

# 8. Animations

Les animations doivent :

* renforcer la progression ;
* donner du feedback ;
* améliorer l'immersion.

Elles ne doivent jamais :

* ralentir l'utilisateur ;
* distraire inutilement ;
* masquer une information.

---

# 9. Accessibilité

Malgré l'identité visuelle forte, le système doit respecter :

* lisibilité ;
* contraste suffisant ;
* navigation claire ;
* compréhension universelle.

---

# 10. Cohérence

Chaque nouvelle interface doit utiliser les éléments existants du Design System.

Les exceptions doivent être justifiées.

---

# 11. Invariants

Le Design System garantit :

* identité visuelle constante ;
* composants réutilisables ;
* expérience cohérente ;
* séparation entre style et logique métier.

---

# 12. Résumé

Le Design System de Project Rebuild transforme une architecture fonctionnelle en une expérience émotionnelle cohérente. Il fournit les règles visuelles nécessaires pour construire un produit immersif, professionnel et durable.
