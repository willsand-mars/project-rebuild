# DOMAIN

Version : 0.1

---

# Objectif

Ce document décrit tous les domaines métier de Project Rebuild.

Chaque domaine est indépendant.

Chaque domaine possède ses propres règles.

Aucun domaine ne doit dépendre directement d'un autre.

Les échanges se font uniquement par des événements ou des interfaces définies.

---

# Vue d'ensemble

Project Rebuild est composé des domaines suivants :

Identity

Profile

Assessment

Goals

Nutrition

Training

Recovery

Progress

Gamification

Coach

Content

Notifications

Analytics

Settings

---

# 1. Identity

Responsabilités :

- gestion des comptes
- authentification
- rôles
- sécurité

Ne connaît jamais :

- nutrition
- entraînement
- progression

---

# 2. Profile

Responsabilités :

- informations physiques

- âge

- sexe

- taille

- poids

- préférences

- langues

Le profil représente la personne.

Jamais son objectif.

---

# 3. Assessment

Mission :

Évaluer l'état actuel.

Produit :

Rebuild Index

Body Type

Fitness Score

Calories de maintenance

Profil sportif

Ne crée jamais de programme.

---

# 4. Goals

Mission :

Stocker les objectifs.

Exemples :

Prendre 8 kg

Courir un marathon

Faire 20 tractions

Perdre 15 kg

Chaque objectif possède :

une date

une priorité

un état
